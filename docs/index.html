怎么用

1先查索引想做什么 → 挑 CLI → 打开能力文档
2照单执行按文档里的命令与 flag 拼，别凭印象造
3查不到就补录往 clis.json 加一条，跑 refresh 固化

新增 / 更新

加一个新 CLI：往 clis.json 加一条记录，然后跑 bin/refresh <名字>。同一类分发方式都不用改脚本；只有碰到全新的分发渠道才需要动 lib/fetchsource.js。

bin/refresh # 刷新全部已收录 CLI，并重建索引 bin/refresh wecom-cli --force # 只刷一个，并强制重新下载源 bin/refresh --list # 看清单里有什么 bin/cli-cap show <名字> <关键词> # 在某个 CLI 的能力面里搜 bin/cli-cap search <关键词> # 不知道用哪个 CLI 时先跨库搜 bin/cli-cap remember <名字> --intent "需求" --command "命令模板" --note "注意事项" bin/cli-cap index # 只重建索引

怎么选采集方式、怎么写解析档，见仓库里的 CONTRIBUTING.md。
