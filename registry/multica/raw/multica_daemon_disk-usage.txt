Walks the daemon's workspaces root and reports per-run or per-workspace disk usage.
Default view is per-run, sorted by size descending. --by-workspace switches to a per-workspace summary;
--top N keeps only the largest N entries.

By default only the current profile's root is scanned. --all-profiles aggregates across every workspace
root — the default root plus each ~/.multica/profiles/* root, including the Desktop app's dedicated
`desktop-<host>` root — and prints a per-root breakdown with a combined grand total. In that mode --top
applies within each root and --workspaces-root is not allowed.

Bytes are split into total and the artifact-cleanable subset (node_modules, .next, .turbo by default,
overridable via MULTICA_GC_ARTIFACT_PATTERNS) so the report stays in sync with what the GC reclaims.
A .git directory counts toward the total but never toward the artifact subset — the GC frees it only
when it removes the whole run directory. Symlinks are never followed.

The STATUS column shows the current status of the issue each directory belongs to, which requires
contacting the server. When the machine is offline, logged out, or the request fails, the column is
left blank and the rest of the report still prints. --by-workspace has no STATUS column and therefore
makes no network request unless --output json is also set. The daemon does not need to be running.

USAGE
  multica daemon disk-usage [flags]

FLAGS
      --all-profiles             Scan every workspace root (default root + all ~/.multica/profiles/* roots, incl. the Desktop app's) and report a combined total
      --by-task                  Per-run view (default; mutually exclusive with --by-workspace)
      --by-workspace             Aggregate output by workspace instead of by run
  -h, --help                     help for disk-usage
      --output string            Output format: table or json (default "table")
      --top int                  Keep only the largest N entries (per root in --all-profiles mode)
      --workspaces-root string   Override the workspaces root path (default: same as the daemon)

INHERITED FLAGS
  --help   Show help for command
