Manage agent skill assignments

USAGE
  multica agent skills <command> [flags]

COMMANDS
  add:   Add skills to an agent without replacing existing assignments
  list:  List skills assigned to an agent
  set:   Set skills for an agent (replaces all current assignments)


FLAGS
  -h, --help   help for skills

INHERITED FLAGS
  --help   Show help for command

LEARN MORE
  Use `multica agent skills <command> --help` for more information about a command.
