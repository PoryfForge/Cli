List an issue's sub-issues grouped by stage

USAGE
  multica issue children <id> [flags]

FLAGS
      --full-id         Show full UUIDs in table output
  -h, --help            help for children
      --output string   Output format: table or json (default "table")

INHERITED FLAGS
  --help   Show help for command

LEARN MORE
  Use `multica <command> <subcommand> --help` for more information about a command.
