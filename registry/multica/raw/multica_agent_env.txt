Read and update an agent's custom environment variables (audited)

USAGE
  multica agent env <command> [flags]

COMMANDS
  get:  Print an agent's custom_env as a JSON map (agent owner or workspace owner/admin; every call is recorded)
  set:  Replace an agent's custom_env (agent owner or workspace owner/admin; values equal to **** preserve the existing entry)


FLAGS
  -h, --help   help for env

INHERITED FLAGS
  --help   Show help for command

LEARN MORE
  Use `multica agent env <command> --help` for more information about a command.
