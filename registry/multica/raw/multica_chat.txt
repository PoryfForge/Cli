Work with the current chat conversation

USAGE
  multica chat <command> [flags]

COMMANDS
  history:  Overview of the channel this conversation is in (messages + thread list)
  thread:   Read one thread's messages (the current thread, or a specific id)


FLAGS
  -h, --help   help for chat

INHERITED FLAGS
  --help   Show help for command

LEARN MORE
  Use `multica chat <command> --help` for more information about a command.
