Start a local Model Context Protocol (MCP) server over stdio so Workbuddy,
Claude Code, or Cursor can call WPS 365 APIs as tools.

凭证与 CLI 相同（config init + auth login --device）。token 不出进程，不监听 TCP。

Usage:
  wps365-cli mcp [command]

Available Commands:
  config      Print MCP client config snippet for Workbuddy / Claude / Cursor
  doctor      Check MCP prerequisites (spec load, credentials)
  serve       Start MCP stdio server (JSON-RPC on stdin/stdout)
  tools       List MCP tools mapped from the curated catalog

Flags:
  -h, --help   help for mcp

Global Flags:
      --dry-run          print the request without sending it
      --flatten          flatten nested objects for columnar outputs
      --jq string        apply a jq filter using the built-in Go engine
      --no-color         disable colorized output
  -o, --output string    output format: json|yaml|table|tsv|ndjson|csv
      --quiet            quiet mode, only output data and errors
      --timeout string   HTTP request timeout for business API calls (e.g. 30s, 2m, 2min; 0/none = no timeout)

Use "wps365-cli mcp [command] --help" for more information about a command.
