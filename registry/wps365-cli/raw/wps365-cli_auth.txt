Authentication and credential management

Usage:
  wps365-cli auth [command]

Available Commands:
  clean       Remove all tokens, credentials, client_id and auto-generated keys
  login       Perform delegated OAuth login
  logout      Delete local delegated token
  qrcode      Encode a URL as a QR code (PNG file or ASCII)
  refresh     Refresh local token
  setup       Save client_id and client_secret
  status      Show current auth status
  token       Print current access token to stdout

Flags:
  -h, --help   help for auth

Global Flags:
      --dry-run          print the request without sending it
      --flatten          flatten nested objects for columnar outputs
      --jq string        apply a jq filter using the built-in Go engine
      --no-color         disable colorized output
  -o, --output string    output format: json|yaml|table|tsv|ndjson|csv
      --quiet            quiet mode, only output data and errors
      --timeout string   HTTP request timeout for business API calls (e.g. 30s, 2m, 2min; 0/none = no timeout)

Use "wps365-cli auth [command] --help" for more information about a command.
