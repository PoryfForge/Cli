Manage authentication

Usage:
  tencentads auth [command]

Available Commands:
  login       Authenticate with Tencent Ads
  logout      Log out and disable the current API key
  status      Show current authentication status

Flags:
  -h, --help   help for auth

Global Flags:
      --config-dir string   Directory for credentials file (default: ~/.tencent-ads)

Use "tencentads auth [command] --help" for more information about a command.
