CLI 1.2.0 验证记录
日期：2026-10-16

本地检查
- 参数与目录校验、默认预览、显式执行、密码不写日志、结果未知时不重跑均通过。
- 压缩上传可还原完整脚本，解压后校验 SHA256；错误摘要会阻止后续执行。
- 连续清理模拟：总限额 5 MiB、单批限额 3 MiB，实际依次按 3、2 MiB 执行后停止。
- 预览只运行首批；被占用导致零删除时停止；第二批结果未知时不运行第三批。
- 已收到明细的部分失败计入已确认删除量，随后停止，不继续清理。
- 多批未设置累计限额时，在询问密码前拒绝执行。
- 清单去重、失败隔离、中止保存、原子写报告及连接加密检查通过。
- 仓库原有 5 组 Node.js 测试全部通过。

实机验证环境
用户授权的一台样板服务器，Windows Server 2012 R2 / Windows PowerShell 5.1。
本轮只对该样板机执行，未扩展到其他服务器。

引擎自检和预览
- SelfTest 通过：仅删除专用目录中的旧测试图片；锁定、只读、变更、近期与指定名称文件得到保留。
- 文件数量、字节与扫描上限检查通过；不进入非数字子目录及目录链接。
- 新增“遇到超出剩余额度的文件，继续选取后续可容纳文件”检查通过。
- 实机自检发现提前退出扫描后目录枚举资源未及时释放，已显式释放并复测通过。
- 内存 API 仅测试自检进程自身，没有对企业微信执行工作集压缩。
- 连续清理预览仅运行一批：候选 5000 个、约 249.18 MiB，实际删除为 0。

  清理前已有的可用空间不计作本工具释放量。
- 每批均保存完整删除明细；核对无重复路径，数量和字节数与累计汇总一致。
- 独立复查：相同目录内超过 30 天的 GUID 图片为 0，扫描错误为 0。
- 7～30 天的 9774 张图片、504344212 字节（约 481 MiB）保留；最近 7 天图片继续保留。
- 五批前后及独立复查中，企业微信主进程的进程号、启动时间一致，复查时进程有响应。
- 没有结束进程、重启企业微信或更改服务器配置；没有清理聊天数据库、登录资料或程序目录。
- 成功运行的工具临时文件全部移除；失败自检留下的专用文件和空测试目录也已清除。

范围限制
清理释放磁盘空间，不等于释放运行内存。
没有验证发单软件实际发图、自动发送恢复、掉线重登或内存泄漏修复。
没有实测其他 Windows 版本、HTTPS 管理入口或数百台实机批次。
多目标失败隔离和中止行为由本地模拟验证。
分享包不包含真实服务器 IP、密码、运维清单或原始运行报告。
