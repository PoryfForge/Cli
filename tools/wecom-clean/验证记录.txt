CLI 1.1.0 验证记录
日期：2026-10-16

本地检查
- 参数与目录校验、默认预览、显式执行、密码不写日志、结果未知时不重跑均通过。
- 压缩传输可以还原完整脚本，解压后校验原始 SHA256；错误摘要会阻止后续执行。
- 压缩当前 16147 字节脚本后为 5477 字节，内容减少约 66.1%。
  对相同脚本，未压缩上传需 17 次远程调用，压缩后需 7 次；不代表清理耗时同比下降。
- 清单支持注释、UTF-8 BOM、重复地址去重，拒绝无效地址、空清单和超过 500 台的清单。
- 清单模式无法接受 --apply，也不能用于 clean / memory。
- 模拟一台失败后继续检查下一台，独立保存状态和资源告警；密码只询问一次。
- 模拟 Ctrl+C：不再检查后续目标，已完成的结果保留，Complete 为 false。
- 模拟本地文件替换失败：原报告仍可读取，没有被截断。
- 仓库原有 5 组 Node.js 测试全部通过。

实机检查（用户授权的单台测试服务器，Windows Server 2012 R2 / Windows PowerShell 5.1）
- 新版脚本压缩上传、解压、SHA256 校验成功。
- SelfTest 通过：仅删除专用目录中的旧测试图片；锁定、只读、变更、近期与指定名称文件得到保留。
- 新增“无候选时扫描仍按上限停止”的测试通过，目录边界保护和文件/字节批次限制通过。
- 内存 API 只测试自检进程自身，没有对企业微信执行工作集压缩。
- 从实际构建、安装的 1.1.0 wheel 运行清单检查；清单重复同一授权地址，实际只检查 1 台。
- 使用 --keep-days 3650 --max-scan 1：报告 Scanned=1、ScanLimitReached=true，
  候选为 0 时仍明确提示后续未检查；汇总 Total=1、Complete=true、退出码为 0。
- 两次实机运行的本地报告都已保存；工具远程临时文件移除成功。
- 本轮没有删除业务临时图片，没有结束进程或修改服务器配置。

历史验证
2026-10-15 的 1.0.0 引擎曾完成 1936 个超过 60 天的旧临时图片清理，约 100 MiB；
删除后核对路径不存在，企业微信主进程未更换。1.1.0 增加了扫描上限和单文件读取异常处理，
删除时的范围、年龄、占用、只读及文件变化校验逻辑未扩大。

范围限制
没有实测其他 Windows 版本、HTTPS 管理入口或数百台实机的完整批次。
多目标失败隔离和中止行为由本地模拟验证；实机清单仅含一台明确授权的服务器。
没有验证发单软件实际发图、自动发送恢复、掉线重登或内存泄漏修复。
分享包不包含真实服务器 IP、密码、运维清单或原始运行报告。
